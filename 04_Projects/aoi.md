# AOI 兴趣区域管理

[返回本章目录](README.md) · [返回手册首页](../README.md)

目的：可见性

## 流程：

### 1.space服务器定时刷新：

100ms一次，创建space时设定

### 2.移动

实体位置变化，无论是客户端发送请求，还是服务器物理推动角色，更新位置和网络，不会立刻便利角色计算进入离开

#### 网络：引擎把地图100/100分成网络单元，用于简化计算流程

### 3.定时器到时，更新AOI：

对于每个角色，计算最大可见距离，得到覆盖的网格，对于网格中的候选实体做精确距离判断

### 4 优化：

将每个实体打成active和stable两种，对于stable而言，可以看周围网络的稳定性，如果稳定，跳过重新计算。

### 5 计算边界：

```
距离小于35：进入
距离35～41：保持原状态
距离大于等于41：离开
```

避免在边界附近反复进出。

### 6 双向关系：

当A进入到B的视野中：

```
A.m_interest[B]       // A正在关注B
B.m_interested[A]     // B被A关注
A.m_interest：A当前能看见哪些实体。
B.m_interested：B发生位置或属性变化时，应该发给哪些观察者。
```
