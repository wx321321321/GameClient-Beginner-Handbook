## 维护约定

1. 新笔记放入对应分区，文件名使用有意义的小写英文与连字符，并更新该分区的 README。
2. 每篇使用一个一级标题；按主题安排二、三级标题。代码放在注明语言的代码块中。
3. 配图放在所属分区的 `assets/`，使用相对路径引用；共用参考资料放在 `resources/`。
4. 可运行的学习源码放在 `examples/`；生成的 EPUB、可执行文件和缓存不作为笔记源文件提交。
5. 与手册无关的本地资料存放在 `.local-archive/`，该目录由 Git 忽略。

本次整理主要统一结构、导航与排版，原有技术笔记仍是学习记录，后续按实际学习进度持续修订。
