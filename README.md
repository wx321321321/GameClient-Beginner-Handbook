# 游戏客户端入门手册

从计算机系统与 C++ 基础出发，逐步学习图形、Unreal Engine，再设计一个射击项目。正文按章、节和小节连续编号，保留原学习笔记、配图与项目经历。

## 按顺序开始

| 章节 | 学习主线 | 篇数 |
| --- | --- | ---: |
| [第一章 计算机系统与 C++](01_CPP%26Computer_Basics/README.md) | 第一个程序 → 硬件与操作系统 → 指针和对象 → 编译与内存 → 模板与容器 → 并发、网络、设计与脚本 | 14 |

| [第四章 从零设计射击项目](04_Projects/README.md) | 10 篇 Arena 设计教程 + 7 篇原项目实践对照 | 17 |
| [第五章 学习安排与复盘](05_StudyPlan/README.md) | 学习计划 → 代码速查 → 面试训练 → 算法题单与复盘 | 5 |

第一次学习请从 [1.1 第一个 C++ 程序](01_CPP%26Computer_Basics/program-and-cpp-basics.md) 开始。每篇跟着例子推演，再运行配套代码、回答自查题。第一遍先抓主线，虚表布局、高级模板、内存序等进阶部分可以在完成基础练习后回读。

第四章用同一个教学项目 Arena 把前面知识串起来：先做本地移动与射击，再完成服务器权威、表现、AI、界面、服务与交付。新教程给出模块设计、C++ 核心例子和验收方法；本仓库仍是学习手册与实验代码，尚不是完整游戏工程。

## 维护方式

1. 在对应主题内补充内容，避免为同一概念再建一份解释；需要复用时链接到主要讲解处。
2. 新增文章时更新 `tools/course-map.json` 和本章目录，再运行编号工具；文件路径保持稳定。
3. 每个例子说明版本、输入、预期结果和边界。纯 C++、UE 工程片段、项目私有接口分别注明环境。
4. 配图放在所属章节的 `assets/`；源码放在 `examples/`；可执行文件、缓存和导出文件不提交。
5. 原实践中的已完成工作、改进设想和待源码核对项如实区分；与手册无关的本地资料留在 Git 忽略的 `.local-archive/`。
