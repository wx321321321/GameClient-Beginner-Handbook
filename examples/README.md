# 学习代码示例

## C++ 与操作系统复习

[cpp-os-review-2026-09-05.cpp](cpp-os-review-2026-09-05.cpp) 是一组 C++17 复习示例，包含重定位与分页的数值模拟、完美转发、智能指针等内容。地址转换示例采用数值模拟。

在本目录使用已安装的支持 C++17 的编译器，例如 GCC：

```sh
g++ -std=c++17 -Wall -Wextra -pedantic cpp-os-review-2026-09-05.cpp -o review.exe
```

生成的可执行文件由 Git 忽略。知识点索引见 [C++ 与计算机基础](../01_CPP%26Computer_Basics/README.md)，复习安排见 [学习计划](../05_StudyPlan/README.md)。
