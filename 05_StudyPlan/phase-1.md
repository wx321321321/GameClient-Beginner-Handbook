# 第一阶段学习计划

[返回本章目录](README.md) · [返回手册首页](../README.md)

学习范围：C++、计算机基础（408）、LeetCode、UE 动画系统。

## 基本目标

| 方向 | 原定目标 |
| --- | --- |
| LeetCode | 除周日外，每日 6 道新题 + 5 道错题。 |
| C++ 与计算机基础 | 每日写一段内容 + 复习一篇。 |
| UE 源码 | 每日写两个模块的源码解析。 |
| 手撕代码 | 每 6 天写一份。 |

## C++ 与计算机基础专题

1. 内存模型。
2. 编译管线。
3. 模板。
4. 动态多态。
5. 关键字。
6. 线程与线程安全。
7. 引用与指针、左值右值。

## 手撕代码专题

1. 智能指针：shared、unique、weak。
2. forward 和 move。
3. 单例。
4. 自旋锁、读写锁、互斥锁。

## UE 源码方向

主要是动画系统方向。

## 原有 C++ 复习安排

复习：内存模型和编译管线。
