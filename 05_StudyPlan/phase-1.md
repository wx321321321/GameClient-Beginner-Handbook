# 第一阶段学习计划

本阶段围绕四条线推进：C++、计算机基础（408）、LeetCode 和 UE 动画系统。原定数量目标保留，下面把“每天做什么”“按什么专题推进”“如何复盘”连起来，避免计划和题单各写一份却无法对应。

## 1. 每日任务与每六天任务

| 频率 | 方向 | 原定目标 | 当次留下的内容 |
| --- | --- | --- | --- |
| 除周日外 | LeetCode | 6 道新题 + 5 道错题 | 新题结果、错因，以及复做能否独立完成 |
| 每日 | C++ 与计算机基础 | 写一段内容 + 复习一篇 | 将新知识放回对应主题，复习时能解释机制和例子 |
| 每日 | UE 源码 | 两个模块的源码解析 | 模块职责、关键类型、调用顺序和上下游关系 |
| 每 6 天 | 手撕代码 | 写一份 | 可运行代码、边界情况，以及与标准库/引擎实现的差异 |

原稿没有规定周日的其他安排，也没有给出每项耗时，这里不替它增加时间承诺。题单中的 Day 编号保留为原题单编号，不自动解释成当前日历日期。

## 2. C++ 与计算机基础的专题顺序

当前明确要复习的是**内存模型和编译管线**。之后把原列出的七个主题接成一条理解链：

| 专题 | 复习时要串起的关系 | 对应笔记 |
| --- | --- | --- |
| 内存模型 | 地址空间、对象存放位置与生命周期 | [内存与编译](../01_CPP%26Computer_Basics/memory-and-compilation.md) |
| 编译管线 | 源代码如何变成目标文件、可执行映像并运行 | [内存与编译](../01_CPP%26Computer_Basics/memory-and-compilation.md) |
| 引用、指针、左右值 | 如何访问对象、表达值类别和资源转移 | [指针与引用](../01_CPP%26Computer_Basics/pointers-and-references.md) |
| 关键字 | 类型转换、限定、链接属性与可调用对象 | [关键字与可调用对象](../01_CPP%26Computer_Basics/cpp-keywords-and-callables.md) |
| 模板 | 实例化、推导、引用折叠与约束 | [模板](../01_CPP%26Computer_Basics/templates.md) |
| 动态多态 | 继承、虚调用、对象模型与析构 | [类与多态](../01_CPP%26Computer_Basics/classes-inheritance-and-polymorphism.md) |
| 线程与线程安全 | 共享数据如何建立正确的同步关系 | [线程与同步](../01_CPP%26Computer_Basics/processes-threads-and-synchronization.md) |

“每日写一段”可以是补齐一个机制、修正一个误解或整理一个例子，不需要为了数量再建一篇内容重复的文章。

## 3. 手撕代码与知识点对应

| 原定专题 | 要通过代码说明的内容 |
| --- | --- |
| 智能指针：shared、unique、weak | 所有权、释放时机、共享与观察者关系 |
| forward 与 move | 值类别转换、模板转发、命名变量仍是左值 |
| 单例 | 创建时机、并发初始化和生命周期 |
| 自旋锁、读写锁、互斥锁 | 竞争时如何等待、谁保护共享数据、适用负载 |

这些练习用于验证理解，不把教学简化版标成可直接替代生产实现。已有 [C++/操作系统复习代码](../examples/cpp-os-review-2026-09-05.cpp) 可以配合使用。

## 4. UE 动画源码阅读

方向继续聚焦动画系统。先以 [动画系统概览](../03_UE/animation-overview.md) 确认正在读的是资源、运行时实例还是动画节点，再把项目里看到的调用链放回 [ALS 实践](../04_Projects/als-locomotion.md) 等笔记中。

每个模块的记录至少能回答：输入是什么、主要维护什么状态、谁调用它、输出交给谁。遇到版本差异或项目自定义类，记下源码位置和待核对点，不把猜测写成引擎固定机制。

## 5. 刷题与复盘的连接

[刷题清单](leetcode-practice.md) 是候选题和原有分日安排，其中每天收录 4、7 或 8 题不等；本阶段“每日 6 道新题”是执行目标，两者不强行改成同一数量。当天从清单选题，实际结果写入 [复盘记录](leetcode-review.md)。

选过、看过题解、独立写对，是不同状态。错题复做时应先独立尝试，再记录是否真正解决了上一次卡点；C++ 基础的口述/选择训练则使用 [面试刷题提示词](cpp-cs-interview-drill-prompt.md)。
