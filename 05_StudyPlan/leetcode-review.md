## 5.5.1 先区分完成状态，再记录错因

| 状态 | 记录含义 |
| --- | --- |
| 未尝试 | 只有题号，尚未独立写过 |
| 卡住/写错 | 已尝试，需要记录卡点或失败用例 |
| 看懂题解 | 已理解一种解法，但还没有独立复现 |
| 独立通过 | 本次能独立完成，不等于之后一定记得 |
| 复测通过 | 隔一段时间后再次独立完成 |

“不会”需要继续拆成原因：没识别问题结构、思路缺一环、复杂度过高、边界漏判、实现错误，或语言/API 不熟。这样下次复习才知道应当检查什么，而不是再抄一次题解。

## 5.5.2 单题复盘模板

```text
日期：
题号 / 题目：
来源：待攻克列表 / 原题单 Day __ / 其他
本次状态：
最初思路：
具体卡点或失败用例：
错误原因：
修正后的核心思路及为什么成立：
关键边界：
时间复杂度 / 空间复杂度：
下次复习日期：
复测结果：
```

记录以自己的思考差距为中心。确实没有找到错因时写“待定位”，不要为了填表编一个结论。

同一题多次复习可以追加记录，但在索引中指向最近一次卡点和下一次安排。
