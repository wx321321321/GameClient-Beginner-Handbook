# 平移旋转缩放相关：

主要是这些变换在游戏引擎中如何传递，以及如何

### 引擎中存储的方式：
##### UE中表示：FTransform：
```
FTransform
{
    FQuat   Rotation;
    FVector Translation;
    FVector Scale3D;
}
```
这么存储的优点：
```
插值方便
旋转用四元数更适合动画混合
比整矩阵更省空间
压缩动画数据更方便
```
##### 动画序列中：
Sequence那边看，单根骨骼的一条轨道，逻辑上就是三类 key

##### 蒙皮阶段计算时：
将平移旋转缩放变成一个矩阵进行传递，GPU 顶点着色器做这种很快。

### 插值
不能直接对矩阵插值，结果不对。
#### 平移：直接线性插值
#### 旋转：四元数球面插值：
四元数会考虑到最短路径以及万向节锁的问题。
#### 欧拉角：用 3 个角度，按某个固定顺序，依次绕 3 根轴旋转，从而描述一个物体的最终朝向。
范围：欧拉角的三个角度理论上可以是任意实数，但一般限制到-180-180中，这样会出现最远距离与最近距离问题，比如-179-179，插值应该是-180而不是0。
欧拉角的最近距离很难处理，而四元数更好处理。
##### 外旋：三个坐标轴是世界坐标轴，不变。
##### 内旋：三个坐标轴是局部坐标轴，随物体旋转变化而变化。
欧拉角既可以是内旋，也可以是外旋，两者可以互相表示。
欧拉角的最大问题是：万向节锁+最短路径。
##### 万向节锁：
```
Yaw   // 绕 Z
Pitch // 绕 Y
Roll  // 绕 X
R = Rz(Yaw) * Ry(Pitch) * Rx(Roll)
Pitch = 90°
此时 Yaw 和 Roll 的效果会变得耦合。你改变 Yaw，再改变 Roll，最终可能只是改变同一个方向上的旋转效果，失去了一个自由度，导致万向节锁。
Yaw 和 Roll 不再能独立决定姿态，会出现同时改变，姿态不变的情况。
```
#### 四元数：
4 个数表示一个三维旋转，并且通过 q * v * q⁻¹ 这种“夹住向量”的方式，把向量旋转到新方向，核心目的就是为了让人看得懂，而是为了让计算机稳定地做旋转组合、插值和避免欧拉角的万向节锁
```
二维旋转：
z = x + yi
r = cosθ + i sinθ
z' = r * z 就是旋转后的结果
```
```
三维旋转：单位四元数，不是单位的会混入缩放。
q = w + xi + yj + zk
q = w + xi + yj + zk
ij = k
jk = i
ki = j
ji = -k
kj = -i
ik = -j
```
```
四元数用半角表示旋转，
axis = (0, 0, 1)
θ = 90°
q.w = cos45°
q.x = 0
q.y = 0
q.z = sin45°
原因：v' = q * v * q⁻¹ 左右各乘了一次
原理：展开后会得到：v' = v cosθ + (n × v) sinθ + n(n · v)(1 - cosθ)
三维旋转里的 Rodrigues 旋转公式，即绕轴 n 旋转 θ 后的向量
```
##### 四元数球面插值：因为单位四元数都在四维单位球面上，Slerp 就是沿着球面最短弧走

##### 如何解决四元数的最短路径：
```
if (dot(q0, q1) < 0)
{
    q1 = -q1;
}

result = Slerp(q0, q1, t);
```

#### 缩放：线性插值

## 蒙皮：

### 线性蒙皮：
当前骨骼姿势相对绑定姿势的变化，按照顶点权重加权作用到顶点上
##### 绑定姿态就是模型和骨骼最初绑定时的姿势。
每根骨骼在绑定姿态下都有一个矩阵，表示它相对父骨骼的位置、旋转、缩放。然后沿父子层级累乘，就能得到它在模型空间/组件空间下的全局绑定矩阵
##### 逆绑定矩阵就是它的逆
作用是把绑定姿态下的位置“反变换”回去，从而从“绑定姿态的模型空间”变回到“相对于这根骨骼的空间”，再应用当前骨骼的动画姿态

##### 糖果纸效应：线性混合旋转
```
解决办法：
1.加 Twist Bone，把手腕的旋转分摊到多根 twist bone 上。
2.让顶点权重过渡更平滑，避免某一圈顶点突然 50/50 混合两个差异很大的旋转
3.某些姿态下触发修正形态。比如前臂旋转到 90° 时，额外加一个形变
4.双四元数插值：对于刚体的变换，使用双四元数表示，双四元数就是两个四元数的组合
Q = qr + ε qd
qr = real part，实部四元数
qd = dual part，双部四元数
线性混合双四元数，然后归一化
混合后更像刚体变换
不擅长处理非均匀缩放，可能出现 bulging鼓包
工具链和引擎支持成本
```
