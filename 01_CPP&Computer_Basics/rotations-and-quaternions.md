# 欧拉角与四元数：旋转表示与使用边界

欧拉角和四元数都可以描述三维姿态，但适合的操作不同。欧拉角适合人查看、输入和限制某个方向；单位四元数更适合运行时组合和姿态插值。旋转表示与平移、缩放一起构成的完整变换，另见 [变换与蒙皮](../02_Graphics/transforms-and-skinning.md)。

## 1. 欧拉角：三个有顺序的旋转

可以把物体想象成装在三层嵌套圆环中，用 Yaw、Pitch、Roll 描述三次旋转：

| 名称 | 直观动作 |
| --- | --- |
| Yaw | 左右转头 |
| Pitch | 抬头、低头 |
| Roll | 歪头 |

本质是按约定组合三个旋转，例如示意式 `R = R_yaw × R_pitch × R_roll`。**这不是脱离上下文的通用执行顺序**：内旋/外旋、坐标系、行向量/列向量以及引擎约定都会影响含义，矩阵乘法也不可随意交换。

### 1.1 万向节锁发生在参数化上

在某些常用的旋转顺序中，当中间角达到约 ±90° 时，原本独立的两个旋转轴可能重合，三个参数对微小旋转的控制不再独立。例如嵌套圆环的 Yaw 与 Roll 在某个姿态下沿同一轴转动。

物体并没有因此“失去旋转能力”；出问题的是这套欧拉角表示在该姿态附近出现奇异性。原笔记记录的表现包括：

- 调整 Yaw 时，看起来产生了类似 Roll 的变化。
- 角度值突然大幅跳动，同一个姿态可以对应多组角度。
- 动画插值经过某些姿态时出现翻转。

万向节锁不是浮点误差。角度跨越 `180° / -180°` 的表示跳变也需要处理，但不应把所有角度跳变都归因于万向节锁。

### 1.2 什么时候仍然适合欧拉角

编辑器显示、美术调参、策划输入，以及相机 Pitch 限制在 `[-80°, 80°]` 这类单方向约束，都适合用欧拉角表达。三个数字直观，但组合顺序重要，逐分量线性插值也未必产生期望的空间旋转路径。

## 2. 单位四元数：轴角的另一种表示

一个三维旋转可理解为绕单位轴 `n` 旋转角度 `θ`。常见单位四元数写作：

```text
q = (n.x · sin(θ/2), n.y · sin(θ/2), n.z · sin(θ/2), cos(θ/2))
```

这里使用 `(x, y, z, w)` 的排列示意；不同库的存储/接口顺序需要确认。四个分量并不表示四个独立旋转自由度，它们受单位长度约束，而且 `q` 与 `-q` 表示同一姿态。

### 2.1 优势与使用要求

单位四元数避免了欧拉角参数化的万向节锁，使用四个数，比 3×3 旋转矩阵紧凑，也适合组合旋转、骨骼姿态和相机计算。

它的代价是不能直观地把某一分量当作“绕某轴多少度”。不要任意改 `x/y/z/w`；累计数值计算后要留意单位长度，必要时归一化。四元数乘法仍不可交换；转回欧拉角时，欧拉角的多解和跳变问题也仍然存在。

### 2.2 Slerp 与 Nlerp

- **Slerp**：沿单位四元数对应的球面弧插值，适合希望按参数匀速旋转的场景。
- **Nlerp**：先线性混合再归一化，计算简单，但一般不保持恒定角速度。

由于 `q` 与 `-q` 表示相同旋转，插值时需要考虑符号一致性；否则线性混合可能走不期望的路径，甚至在相反四元数之间得到接近零的中间量。应使用符合需求的引擎插值接口，并确认它是否采用最短路径。

## 3. UE 中的 FRotator、FQuat 与 FTransform

UE 常用 `FRotator` 表示便于阅读的角度，用 `FQuat` 处理四元数旋转。`FTransform` 在概念上保存旋转、平移和缩放：

```cpp
// 概念示意，不是特定 UE 版本的完整源码布局。
struct FTransformConcept
{
    FQuat Rotation;
    FVector Translation;
    FVector Scale3D;
};
```

CPU 上可以直接用变换接口处理位置或向量，无须每次都先手写一个矩阵。向 GPU 批量提交顶点/骨骼变换时，常见路径会转换成矩阵或打包后的变换数据，但**GPU 并非只能接收 4×4 矩阵**：实际表示还可能是 3×4 矩阵、四元数加平移等，取决于渲染/蒙皮路径。

因此，原来的“CPU 用 FTransform，GPU 必须转 4×4”应理解为一种常见工程流程，不能当作硬性规则。非均匀缩放与旋转组合的边界，还应结合 `FTransform` 的表示能力和具体运算核对。

接口对照：[Epic：TQuat](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/Core/TQuat)、[Epic：TTransform](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/Core/TTransform)。
