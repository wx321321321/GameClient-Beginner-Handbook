# 计算机组成原理

## 1.冯诺依曼机：

计算机硬件系统由运算器、存储器、控制器、输入设备和输出设备 5 大部件组成。
指令和数据以同等地位存储在存储器中，均用二进制代码表示，但计算机应能区分它们。
指令由操作码和地址码组成，操作码指出操作的类型，地址码指出操作数的地址。

## 硬件：

### CPU：

控制单元 CU（Control Unit）主要负责指令的控制与执行。
算术逻辑单元 ALU（Arithmetic Logic Unit）处理实际的数学运算和逻辑运算。

#### 寄存器（Registers）用于临时存储指令、数据或操作结果，是 CPU 内部的高速存储设备。

通用寄存器 GPR：累加 ACC、乘商 MQ、操作数寄存器 X、变址寄存器 IX、基址寄存器 BR 等。
主存地址寄存器 MAR：存放将要访问的主存单元的地址，位数与地址码长度相同.
主存数据寄存器 MDR：存放从主存中读取的数据或将要写入主存的数据，位数与存储字长相同，
指令寄存器 IR：存放当前执行的指令代码，位数取决于指令字长。
程序计数器 PC：存放下一条指令的地址，位数取决于存储器字数和指令字长，具有自增功能
程序状态寄存器 PSW：存放标志信息。

## 计算机基础：

### 字长：

机器字长指的是 CPU 一次整数运算的数据通路宽度，等于其 ALU 和通用寄存器宽度
存储字长是指主存单元​​一次存取操作的位数，等于数据总线宽度，
指令字长是指一条指令在内存中的​​编码长度​​，取决于具体指令集架构，等于其指令寄存器宽度，会影响指令的复杂性和指令集的大小。
CPU 寻址空间是指 CPU 理论可以直接访问的内存范围，与地址总线宽度有关。

### 指标：

CPU 时钟周期 TTT ：机器内部主时钟脉冲信号的宽度，是 CPU 工作的最小时间单位。
CPU 时钟频率 fff ：也称主频，即每秒的时钟周期数，越大指令执行越快。
CPI 是执行一条指令所需的时钟周期数，与指令集、架构和计算机组织等有关，Cache 缺失率影响。

### 数字：

0b二进制、0/0o八进制，0x十六进制
现代计算机基本都采用字节编址，即每个地址编号中存放 1 字节。不同类型的数据占用的字节数不同，如 int 型和 float 型占 4 字节，double 型占 8 字节等，而程序中对每个数据只给定一个地址

### 大端 big endian 先高位后低位存储；小端 little endian 先低位后高位存储

### 定点整数：

原码：最高位（左边）为符号位，如 +5 原码为 00000101，-5 原码为 10000101。
反码：正数的反码同原码，负数的反码将其原码除符号位外全部取反，如 -5 反码为 11111010。
补码：正数的补码同原码，负数的补码是在其反码的基础上加 1，如 -5 补码为 11111011。
移码：真值加上偏置值，可直接由其补码符号位取反得到，只用于定点整数的表示，常用于浮点数的阶码。

#### 原码反码最小值都是2^n-1，但补码的最小值是2^n，因为表示0只有1个数，

#### 补码是最常用的

因为它简化了硬件设计，使得加法和减法可以通过相同的电路实现，也解决了原码和反码在表示 0 时的二义性问题。
在c语言中，都是按补码形式存储的，只是有符号整数的最高位代表符号，而无符号整数的全部二进制位都表示数值，没有符号位，相当于数的绝对值，因此两者所表示的数据范围有所不同。

### 定点小数：

实际上就是规定小数点左移几位，算完之后直接用结果一除就行。

#### 浮点数：

组成：符号、阶码（补码）、尾数
IEEE标准：
32位短浮点数：1、8、23
64位：1、11、52
默认小数点前有个1
阶码全 0 尾数不全为 0 表示非规格化数，此时隐藏尾数位是 0 不是 1，阶码全 1 尾数全 0 表示无穷大的非数 NaN。

## 存储系统：

### 结构：

CPU寄存器-》cache-》内存-》外存

#### RAM与ROM

主存两个都有，RAM读写、ROM只读
RAM 是计算机中用于临时存储数据和程序的主要内存设备，读写速度快，但是断电后数据会丢失，因此属于易失性存储器。
ROM 结构简单位密度高，其中存储的数据一旦被写入，就不能轻易修改或删除，具有不易擦写、永久存储、快速访问和随机存取的特点
SRAM 速度快且不用周期性刷新电路，但成本高功耗大，集成度较低，常用于高速缓存如 Cache、TLB 等。
DRAM 电容漏电会需要周期性频繁重写数据，常用于主存储器如内存条等

#### 外存

扇区是磁盘读写的最小单位，包含数据、地址和校验等信息。文件实际存放磁盘及其读写均以块为单位。
磁头数：即记录面数，磁头用于读取盘片上记录面的信息和写入信息，一个记录面对应一个磁头。
柱面数：即每面磁道数。在一个盘组中，不同记录面的相同编号（指磁道号）的磁道构成一个柱面。
扇区数：即每条磁道上有多少个扇区。磁盘的物理地址：磁道号+盘面号+扇区号可以唯一确定磁盘块的位置。
外存与内存之间交换页（一个页可能等于多个扇区），内存与cache之间交换块

### cache   SRAM

#### 程序局部性原理：

时间局部性：如果一个数据被访问了，那么它在之后也很可能再次被访问。例如程序中的循环结构和调用过程。
空间局部性：如果一个数据被访问了，那么它内存中相邻数据也很可能很快被访问。例如程序中的数组、结构体成员、顺序执行的代码块以及指令流通常顺序存放。

#### 多级cache：

L1 Cache 位于 CPU 内部，速度最快但容量最小，用于存储最频繁访问的数据和指令，严格分成两部分。
L2 Cache 通常也集成在 CPU 芯片上，容量较大但速度略慢，用于扩展并提高缓存命中率。
L3 Cache 通常位于 CPU 芯片外部，但仍然与 CPU 连接紧密，容量最大但速度相对较慢，用于为多个 CPU 核心提供共享的高速缓存，以减少核心之间的竞争，提高系统整体性能。
为便于 Cache 与主存交换信息，Cache 和主存都被划分为大小相等的块，Cache 块由若干字节组成，块数要远少于主存中的块数，即 Cache 中仅保存主存中最活跃的若干块的副本。

#### 写命中：

当 CPU 发出写请求时，若 Cache 命中，有可能遇到 Cache 与主存中的内容不一致的问题，则需要按照一定的写策略处理，写命中处理方法有以下两种：
直写法：必须同时将数据写入 Cache 和主存。实现简单安全但增加了访问次数，降低了 Cache 效率，可能导致写缓冲饱和和溢出。L1 Cache 对 L2 Cache 使用
回写法：数据先写入 Cache 不立即写入主存，只有在被替换出 Cache 时才写回主存。减少访问次数提高效率，但存在数据不一致的隐患。L2 Cache 对主存使用

#### 写不命中：

写分配法：更新主存单元，然后将主存块调入 Cache，利用程序的空间局部性。
非写分配法：只更新主存单元，不将主存块调入 Cache。

#### Cache 和主存的映射方式

1.直接映射：比如64个内存块，8个cache块，那么用64/8，根据余数来判断该内存应该存入到那个内存块。
2.全相联：内存块可以存入到任意的cache中。
3.组相联：内存块可以存到对应的组中。

#### 主存块的替换算法

LRU 算法：基于局部性原理，选择最近最久未访问过的 Cache 行进行替换
LFU 基于局部性原理，对访问次数最少的数据消灭。
RAND 算法：随机确定替换的 Cache 行，实现简单命中率低。
FIFO 算法：对每个 Cache 行打一个时间戳记录何时装入新主存块，选择最早调入的 Cache 行进行替换。

#### 缓存一致性协议：

缓存管理的单位通常是整条Cache Line，例如64B，经典的MESI协议。
![缓存一致性](assets/cache-coherence.png)
Cache Line只是被动保存：Tag（地址标记）+ Data（数据）+ MESI状态，由cpu里面的一致性控制器对信号进行管理

##### 结构：本地缓存控制器管理自己的Cache,直到有哪些地址存入了cache，全局一致性目录或广播监听机制协调其他Cache。

##### 一次流程：

```
初始：
变量：X
初始值：0
X所在Cache Line：L
```

```
步骤0：初始状态
内存：X=0
C1：L没有记录
C2：L没有记录
```

```
步骤1：C1读取X
C1执行：read X
C1缓存控制器：发现L不合法，发出GetS(L)
一致性控制器：发现没有其他核心持有L，从内存返回L
C1缓存控制器：将L写入C1 Cache，状态设为E
结果：
内存：X=0
C1：L=E，X=0
C2：L没有记录
```

```
步骤2：C2读取X
C2执行：read X
C2缓存控制器：发现L为I，发出GetS(L)
一致性控制器：发现C1以E状态持有L，向C1发送Snoop Read
C1缓存控制器：返回L，将C1中的L从E改为S
C2缓存控制器：接收L，将状态设为S
结果：
内存：X=0
C1：L=S，X=0
C2：L=S，X=0
```

```
步骤3：C1写入X=1
C1执行：write X=1
C1缓存控制器：发现L为S，没有写权限，发出Upgrade/GetM(L)
一致性控制器：向C2发送Invalidate(L)
C2缓存控制器：将L从S改为I，返回ACK
一致性控制器：收到全部ACK，将写权限授予C1
C1缓存控制器：将L从S改为M，写入X=1
结果：
内存：X=0
C1：L=M，X=1
C2：L=I
```

```
步骤4：C2读取X
C2执行：read X
C2缓存控制器：发现L为I，发出GetS(L)
一致性控制器：发现最新数据在C1的M状态Cache Line中
一致性控制器：向C1发送Snoop Read
C1缓存控制器：返回最新的L，X=1
C1缓存控制器：将L从M改为S
内存控制器：将最新值X=1写回内存
C2缓存控制器：接收L，将状态设为S
结果：
内存：X=1
C1：L=S，X=1
C2：L=S，X=1
```

```
步骤5：C2写入X=2
C2执行：write X=2
C2缓存控制器：发现L为S，发出Upgrade/GetM(L)
一致性控制器：向C1发送Invalidate(L)
C1缓存控制器：将L从S改为I，返回ACK
一致性控制器：将写权限授予C2
C2缓存控制器：将L从S改为M，写入X=2
结果：
内存：X=1
C1：L=I
C2：L=M，X=2
```

```
步骤6：C2淘汰Cache Line
C2缓存控制器：发现L为M，必须先写回
C2缓存控制器：将L中的X=2发送给内存控制器
内存控制器：更新内存X=2
C2缓存控制器：将L从M改为I
结果：
内存：X=2
C1：L=I
C2：L=I

```

### 内存管理

对于逻辑地址，即是各个程序内部的地址，类似每一个程序段的地址都是从零开始编址，而物理地址，则是内存中实际的编址方式

#### 虚拟地址：

就是操作系统和硬件一起给每个进程“伪造”出一套独立、连续、很大的地址空间。

#### 为什么用：

隔离保护共享按需分配统一抽象

#### 从虚拟地址到物理地址

MMU（Memory Management Unit，内存管理单元）把虚拟地址翻译成物理地址。
先查TLB快表，没有查页表，还没有说明没这个页，os介入，分配空间，写入页表
每一套进程都有自己的页表、以及虚拟内存空间，从0开始

#### 程序的装入，执行要将外存的程序装入到内存中：

绝对装入方式，此种方式只适合单道程序的系统，且需要预先知道程序会放在内存的哪个位置，此时程序中的逻辑地址是和内存中的物理地址是一一对应
重定位装入方式，也叫静态重定位，这种方式下的装入，是在装入的时候将程序中的逻辑地址转换为物理地址。这种方式一旦装入了，那么对应的物理地址也就成型了，那么程序就不能在内存空间中移动了
动态重定位，顾名思义，此种方式是指在将程序装入到内存的时候并不立即将逻辑地址转换为物理地址，只有等到程序要真正开始运行的时候才将逻辑地址转换为物理地址，因此这种方式能够允许程序在内存中移动。但是这种方式需要一个动态重定位寄存器

#### 基本分页管理

因此提出了页表的概念，页表中记录着每个进程的逻辑页所对应的物理页，可以采用随机访问的技术

#### 基本分段管理

是对于段表的设计，其目的是便于用户操作，对于用户来说，页是不可见的，但是段是可见的，对于一个用户的程序，其可以分为若干个大小不等的段，因此一个进程也会对应一个段表，由于段的大小长度是不等的自描述协议

#### 页面置换算法：

LRU\先进先出\clock时钟、自描述协议

#### 抖动

是指出现了频繁的页面的换入和换出的现象，以至于cpu大部分的时间都在忙于这个事从而使系统的吞吐量急剧下降的现象，出现这种现象的主要原因在于页面不足或置换算法不佳

#### 工作集：

是指从当前时刻开始向前的若干个时刻中用过的页面的号，工作集往往反映了进程经常使用的几个页面。驻留集的大小应不小于工作集的大小，否则会出现频繁的页面换入换出现象。

### 指令系统：

#### 指令类型

指令字长 ：单字长指令：半字长指令：双字长指令：
定长指令系统：所有指令的长度都相等，指令字最高位部分分配固定的若干位表示操作码，结构简单有利于指令顺序寻址取址和译码，但扩展性差。
变长指令系统：所有指令的长度都可变，指令字的操作码字段位数不定且分散不同位置上，结构灵活较难实现，可扩展性好且冗余少。

#### 地址码数目的不同

零地址指令：只给出操作码 OP，没有显式地址，也称堆栈运算指令，参与的两个操作数来自栈顶和次栈顶单元，用于空操作指令、停机指令、关中断指令等。
一地址指令：包含操作码 OP 和地址 A1，操作数按地址 A1 读取操作数，执行 OP 操作，另一个操作数通常存放在 ACC 中属于隐含寻址，结果存回 A1。
二地址指令：包含操作码 OP 和两个地址 A1、A2，用于算术和逻辑运算指令，操作数来自 A1 和 A2，结果存入A1。
三地址指令：包含操作码 OP 和三个地址 A1、A2、A3，用于子程序控制指令，操作数来自 A1 和 A2，结果存入 A3。
四地址指令：包含操作码 OP 和四个地址 A1~A4，用于转移指令，操作数来自 A1 和 A2，结果存入 A3，A4 为下一条指令地址。

#### 寻址方式：

指令寻址方式有两种，一种是顺序寻址方式，另一种是跳跃寻址方式。
数据寻址方式较多，通常在指令字中设置一个寻址方式字段区别寻址方式
若为立即寻址，则形式地址的位数决定了操作数的范围。
若为直接寻址，则形式地址的位数决定了可寻址的范围。
若为寄存器寻址，则形式地址的位数决定了通用寄存器的最大数量。
若为寄存器间接寻址，则寄存器的位数决定了可寻址的范围。

```
立即：A 是数据
直接：A 是地址
寄存器：A 是寄存器编号
寄存器间接：A 选寄存器，寄存器内容才是地址
```

### 中断与异常

异常（内中断）：CPU 执行一条指令时，在其自身内部检测到、与正在执行的指令相关的同步事件。
中断（外中断）：由 CPU 外部设备请求触发、与正在执行的指令无关的异步事件，不阻止指令完成。

#### 异常分为：

软件中断
故障（Fault）指在引起故障的指令启动后和结束时被检测到的异常事件，如缺页、除 0、非法指令等，内核程序可以修复。断点为当前发生异常的指令的地址。自陷（Trap）是由访管或陷入指令引发的人为异常，如系统调用、调试断点、单步执行等。断点为访管或陷入指令下一条指令的地址。终止（Abort）是在执行指令过程中随机发生了硬件故障，如控制器出错、存储器校验错、总线错误等，内核程序也无法修复，需调出异常服务程序来重启系统。断点可以是当前指令或下一条指令的地址。

#### 硬故障中断

中断分为可屏蔽和不可屏蔽，常见有 I/O 中断、时钟中断、键鼠输入、DMA 传送等。

### 异常和中断响应过程

CPU 执行指令时，若发生异常或中断请求，响应中断必须满足以下条件：
中断请求触发器处于 1 状态保持信号，且 CPU 允许开中断（检测到请求即响应）。
外设中断允许 IF 触发器处于 1 状态保持信号。
当前指令执行完毕，无更高优先级任务。

#### 中断隐指令：

由 CPU 硬件执行中断隐指令（不在指令系统）作出异常和中断响应：
​​关中断​​：为防保存断点和程序状态期间被新中断打断，设置中断允许触发器为 0 禁止响应新中断。
​​保存断点和程序状态​​：将程序断点（返回地址）、PC 和 PSW 压入栈中，以支持嵌套及恢复执行。
​​识别并转对应处理程序​​：软件识别是 CPU 设异常状态寄存器，操作系统用查询程序按优先级检测异常和中断类型并转内核处理程序；
硬件识别即向量中断，中断向量是中断处理程序的入口地址，存在中断向量表中，根据中断向量对应的类型号快速找处理程序

##### 不可屏蔽中断仍会进行。

##### 关中断，分为全局屏蔽和优先级屏蔽，如果是后者，高优先级可以抢断，但也必须在两条指令之间，为cpu体系规定的可中断点。

#### 中断处理程序：

操作系统启动中断服务程序并执行，整个过程不可打断：
保护现场：操作系统保存当前程序的寄存器状态和中断屏蔽字等
中断事件处理：执行具体的中断服务逻辑。
恢复现场：恢复保护的寄存器状态，由关中断指令完成。
开中断：为后续中断响应做准备，此时每条指令执行结束时采样中断信号，检测到就立即响应。
中断返回：执行最后的返回指令，自行直接返回原程序。
