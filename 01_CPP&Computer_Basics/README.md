# 第一章 计算机系统与 C++

[返回手册首页](../README.md)

从 1.1 开始逐篇阅读。先会跟踪一个小程序，再解释硬件和操作系统，随后深入 C++ 的对象、内存、泛型与并发。每篇先学主线，再看文内进阶部分；不要在第一次阅读时被 ABI 或高级模板细节卡住。

## 怎样学这一章

1. 先读问题与例子，自己推演输出，再运行 [配套实验](../examples/course/README.md)。
2. 把地址、对象、所有权分开画；遇到线程和网络，再补上时间顺序与状态所属方。
3. 完成文末练习后再前进，复习时按章节号回查。C++17 是配套实验基线，C++20 的 `requires` 单独标明。

每个主题保留一个主要讲解位置：生命周期与所有权在 1.4/1.5，编译和地址空间在 1.7，同步规则在 1.10，网络消息在 1.11；其他篇通过链接引用。配图继续保存在 assets 中。
